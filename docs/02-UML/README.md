# UML 图集

本目录存放 PlantUML 源文件与导出的图片，命名规则为 `编号-名称.puml`。

| 编号 | 图名 | 内容要点 | 建议负责人 |
|---|---|---|---|
| UML-01 | 用例图 | 普通用户、分析人员、管理员三类角色，12 个用例 | 占竞 |
| UML-02 | 类图 | 领域配置、适配器、仓储、服务、蓝图五层共 14 个类 | 魏铃峻霏 |
| UML-03 | 时序图-采集 | 调度器 → 适配器 → 仓储 → 版本快照 → 推送 | 陈灵湘 |
| UML-04 | 时序图-对话 | 前端 → Socket.IO → 大模型 → 数据上下文 → 回传 | 付惊安 |
| UML-05 | 状态图 | 数据源状态：空闲 → 采集中 → 成功 / 异常 | 占航溢 |
| UML-06 | 部署图 | 浏览器、Flask、MySQL、定时任务、模型服务 | 李艺森 |

绘制方式：

1. 安装 PlantUML 插件（VS Code）或使用在线编辑器；
2. 源文件保存在本目录，导出 PNG 到 `docs/02-UML/images/`；
3. 图片在 `docs/01-需求规格说明书.md` 中引用。
