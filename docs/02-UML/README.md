# UML 图集

本目录存放 PlantUML 源文件与导出的图片，命名规则为 `编号-名称.puml`。
图集在设计阶段产出，内容以 `docs/01-需求规格说明书.md` 为依据。

| 编号 | 图名 | 内容要点 | 依据需求 |
|---|---|---|---|
| UML-01 | 用例图 | 浏览者、分析者、管理员三类角色，14 个用例 | UC-01 至 UC-14 |
| UML-02 | 类图 | 领域配置、适配器、仓储、服务、蓝图、Agent 工具注册表 | 第 5、6 章 |
| UML-03 | 时序图-数据采集 | 调度器 → 适配器 → 清洗去重 → 仓储 → 版本快照 | FR-01、FR-04、FR-07 |
| UML-04 | 时序图-对话 | 前端 → Socket.IO → Agent → 模型 → 工具 → 回传 | FR-17 至 FR-21 |
| UML-05 | 时序图-Agent 工具编排 | 意图识别 → 参数补全 → 工具执行 → 结果组织 | FR-18、FR-19 |
| UML-06 | 状态图-数据源 | 空闲 → 采集中 → 成功或异常 | FR-25 |
| UML-07 | 部署图 | 浏览器、Flask、MySQL、定时任务、模型服务 | NFR-10 |

绘制方式：

1. 安装 PlantUML 插件（VS Code）或使用在线编辑器；
2. 源文件保存在本目录，导出 PNG 到 `docs/02-UML/images/`；
3. 图片在需求或设计文档中引用。
